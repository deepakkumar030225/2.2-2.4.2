# ml-experiments

A repository for machine learning experiments and projects.

## Overview

This repository contains various machine learning experiments, including data exploration, model training, and evaluation scripts.

## Structure

- `experiments/` - Individual ML experiment scripts
- `data/` - Datasets and data processing utilities
- `models/` - Trained model files and definitions
- `notebooks/` - Jupyter notebooks for exploratory analysis

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run an experiment:
   ```bash
   python experiments/train.py
   ```

## Requirements

- Python 3.8+
- scikit-learn
- numpy
- pandas
- matplotlib
